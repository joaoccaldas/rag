# RAG Reference Project

This public branch has been quarantined after a privacy and employer-data review.

The previous default-branch tree mixed a reusable RAG implementation with environment-specific names, local machine paths, and work-context examples. Those artifacts are intentionally removed from the current public branch rather than being presented as generic open-source material.

## Public repository policy

Only generic, synthetic, non-confidential examples should be committed here.

Do not commit:
- employer, client, or internal strategy material;
- production documents or embeddings;
- real financial or operational data;
- personal absolute filesystem paths;
- API keys, tokens, cookies, credentials, or `.env` files;
- personal or professional contact data.

A clean generic implementation can be rebuilt here from synthetic fixtures after the private/work-specific material has been separated.

## Important

Older Git commits may still contain removed material. The default branch quarantine is an immediate containment step, not a Git-history purge. History must be rewritten or the repository replaced before treating old public commits as remediated.
